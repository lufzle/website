Privacy Policy

Last updated September 11, 2026

1. Scope

This Privacy Policy explains how the foldelight macOS application handles information. foldelight processes the screen image and lid angle locally so it can render the folding effect. It does not create an account, show advertising, or send app data to a server.

2. Information foldelight processes

foldelight processes live frames from your built-in display and a numerical reading from your MacBook’s lid-angle sensor. It also reads and stores the settings that you choose in the app.

3. Screen Recording permission

macOS requires permission before an app can capture the screen. While the desktop effect runs, foldelight uses Apple’s ScreenCaptureKit to receive live frames from the built-in display. It keeps each frame in memory, reprojects it with the graphics processor, draws it on a full-screen overlay, and replaces it with the next frame. foldelight excludes that overlay from capture to prevent a recursive image.

  • Normal effect operation does not write screen frames to disk.
  • No screen frame or other app data leaves your Mac. foldelight makes no network requests.
  • foldelight disables system-audio and microphone capture.
  • Pausing the effect or quitting foldelight stops live effect capture.

If you explicitly start the 15-second diagnostic recording from the menu, foldelight saves a local MP4 in the private foldelight-debug temporary folder. The recording includes the pointer and never includes audio. This user-started diagnostic is the only feature that writes screen images to disk.

You can revoke permission in System Settings → Privacy & Security → Screen & System Audio Recording. The live effect stops working until you grant permission again.

4. Lid-angle sensor

foldelight reads a single numerical hinge angle from the sensor in a compatible Apple silicon MacBook. It uses that number to drive the effect and does not transmit it.

During normal operation, the angle stays in memory. If you enable Debug, a local temporary log can include the current angle and aggregate sensor timing information.

5. Information stored on your Mac

foldelight stores your Blur, Vignette, and activation-angle settings in standard macOS preferences. It also stores whether Debug is enabled. The app does not send these settings anywhere.

When Debug is enabled, foldelight writes local text logs to the private foldelight-debug temporary folder. A diagnostic MP4 appears there only when you start a recording. Delete the app’s preferences to remove its saved settings. Delete the temporary folder to remove its logs and recordings.

6. How foldelight uses information

foldelight uses screen frames and lid-angle readings only to render the effect that you requested. It uses local settings to restore your preferred configuration. It uses local debug information only to help diagnose performance or compatibility problems.

7. Sharing and network activity

foldelight does not sell, share, or transmit screen frames, lid-angle readings, settings, logs, or recordings. The app makes no network requests.

The foldelight webpage is static. Its client code does not set cookies, run analytics, or send form data. Links to other websites are governed by those websites’ privacy policies.

8. Retention and deletion

Live frames and lid-angle readings remain in memory only as needed to render the effect. Each screen frame is replaced by the next frame.

Your settings remain in macOS preferences until you delete them. Debug logs and diagnostic recordings remain in the temporary folder until you or macOS delete them.

9. Your choices

You can pause the effect, disable Debug, or quit foldelight at any time. You can revoke Screen Recording permission in macOS System Settings. You can delete the app’s preferences, logs, and diagnostic recordings from your Mac.

10. Security

foldelight keeps app processing on your Mac. Its debug folder uses private local permissions. No method of storage is completely secure, so you should remove diagnostic files when you no longer need them.

11. Children’s privacy

foldelight is not directed to children and does not knowingly collect personal information from children.

12. Changes to this policy

This policy may change when foldelight’s features or data practices change. The date at the top shows the latest revision.

13. Contact

For privacy questions, open an issue in the foldelight GitHub repository.
