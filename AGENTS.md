## Development

Use `bun` for all package management and scripts (`bun install`, `bun run build`, `bun run dev`).

When starting the dev server, use background mode:

```
bun x astro dev --background
```

Manage the background server with `bun x astro dev stop`, `bun x astro dev status`, and `bun x astro dev logs`.

## Writing

Posts in `src/content/posts/` follow the house style in [WRITING.md](WRITING.md).

Read it before drafting or editing any post. It catalogues the phrasing patterns to avoid
(negative parallelism, fragment staccato, paragraph-final aphorisms, stage directions, the
significance gloss) and ends with a revision checklist to run before publishing.
